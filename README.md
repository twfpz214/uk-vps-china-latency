## AS9929、CN2 GIA、CMIN2：线路名对应的实际差别

AS9929是联通CUII（China Unicom International Infrastructure），对标电信CN2 GIA（AS4809）和移动CMIN2（AS58807），三家各自铺的高端骨干，承载对延迟和丢包敏感的流量。普通163骨干是AS4134，普通联通骨干是AS4837，和上面几条不在一个级别。

英国的9929流量一般这么走：伦敦出发经联通国际AS10099（China Unicom Global）到法兰克福联通POP，再横跨欧亚进CUII回国。AS10099是联通国际的承载网，不是CUII本身，两者常一起出现。

去程和回程可以不一样。有的商家回程三网强制走AS9929，去程电信仍然绕美：国内163骨干到美西圣何塞电信POP，经telia转美东纽约，跨大西洋到伦敦。结果是电信用户ping比联通高一截，但晚高峰不炸。这就是"回程优化"和"双向优化"的区别，买之前要问清是只优化回程还是两头都管。
